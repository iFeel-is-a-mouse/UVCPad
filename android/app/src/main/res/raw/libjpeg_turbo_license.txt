libjpeg-turbo License
=====================

本文件说明随 hdmi2mp APK 分发的 libjpeg-turbo（native 库 libjpeg-turbo313.so，由
AUSBC/AndroidUSBCamera 依赖链带入）的许可证条款。

libjpeg-turbo 以两份兼容的 BSD 风格开源许可证覆盖：
  * IJG（Independent JPEG Group）License —— 适用于 libjpeg API 库及关联程序，
    包括继承自 libjpeg 的代码及其修改；
  * Modified (3-clause) BSD License —— 适用于 TurboJPEG API 库及关联程序、
    libspng 及构建/测试系统。

两份许可证全文如下，取自 libjpeg-turbo v3.1.3 官方发布
（https://github.com/libjpeg-turbo/libjpeg-turbo）。

按 IJG License 条款，二进制分发需在产品文档中声明：
  "This software is based in part on the work of the Independent JPEG Group."
（本软件部分基于 Independent JPEG Group 的工作成果。）
